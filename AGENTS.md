# AI Company Index

## AI Company Roles
1. **[CEO (Human)](company/CEO.md)**: Product Owner, Business Vision, Final Approvals. The founder should not manually manage every AI tool.
2. **[Antigravity (Manager/Frontend)](company/ANTIGRAVITY_MANAGER.md)**: Main Orchestrator, UX, Product Management, React/Next.js UI.
3. **[Claude (Backend CTO)](company/CLAUDE_BACKEND.md)**: Supabase, Server Actions, RLS, Database Migrations.
4. **[Codex (Reviewer/QA)](company/CODEX_REVIEWER.md)**: Security audits, RLS validation, PR reviews.
5. **[OpenRouter (Advisor)](company/OPENROUTER_ADVISOR.md)**: Second opinions, structured JSON, research.
6. **Stitch**: UI design ideation.
7. **Lovable**: UX experiments and prototypes.
