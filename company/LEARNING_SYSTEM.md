# AI Company Learning System

## Purpose
Define how agents learn from execution, testing, and feedback.

## Learning Cycle
1. Task Execution
2. Validation & Review
3. Quality Scorecard Evaluation
4. Lesson Extraction
5. Rule Update & Prevention Framework

## What Can Be Learned
- Workflow improvements
- Better tool selection rules
- Recurring code quality issues
- UX improvements based on feedback

## What Cannot Be Learned (Forbidden)
- Bypassing RLS or security checks
- Overriding CEO decisions without explicit consent
- Accessing PHI or real data to derive patterns

## Privacy Rules
- No real data, patient names, or clinic financial data in learning logs.

## Update Approval Rules
- New prevention rules or modifications to the learning system require CEO approval.

## Mistake Prevention Framework
When a mistake occurs:
1. Log in `LESSONS_LEARNED.md`.
2. Define the "Prevention Rule".
3. Apply rule to the relevant agent's `company/` instruction file or `TOOL_ORCHESTRATION.md`.
