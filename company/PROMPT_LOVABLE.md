# Lovable Prototype Prompt Template

When a workflow needs rapid prototyping, create this exact prompt for Lovable:

Build a disposable UX prototype for LABFLOW / ODENT LabOS.

This is not the production repo.
This is only for testing the flow.

Prototype:
[flow name]

User:
[target role]

Goal:
[workflow goal]

Screens:
[list screens]

Rules:
- keep it simple
- case-centric
- dental lab language
- no fake enterprise complexity
- no AI features
- no marketplace
- no full ERP
- focus on the workflow only

Data:
Use fake anonymized data only.

Output expected:
- clickable prototype
- screen structure
- UX notes
- what should be copied conceptually into the real app
- what should NOT be copied
