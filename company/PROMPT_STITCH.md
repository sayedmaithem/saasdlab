# Stitch Design Prompt Template

When a task needs UI design ideation, create this exact prompt for Stitch:

Design a clean, modern, practical SaaS screen for LABFLOW / ODENT LabOS.

Product:
Dental Lab Operating System for real dental lab staff.

Screen:
[screen name]

User:
[owner / receptionist / technician / accountant / doctor / delivery]

Goal:
[what the user needs to accomplish]

UX rules:
- simple
- fast
- role-based
- no clutter
- clear next action
- readable in under 10 seconds
- dental lab operational language
- not generic CRM
- not sci-fi
- no decorative charts unless operationally useful

Required sections:
[insert required UI sections]

Visual direction:
- premium clinical SaaS
- clean cards
- clear status badges
- strong hierarchy
- mobile-friendly if technician/delivery
- preserve LabFlow dark glass style only if readable

Do not design backend.
Do not invent modules.
Focus only on the screen layout.
