# R.O.C.T.C.F Task Template

When communicating tasks between agents or from human to agent, ALWAYS use the following markdown template.

```markdown
## R.O.C.T.C.F Breakdown

### R — Role
[State the specific agent or human role, e.g., "Antigravity as Frontend Lead"]

### O — Objective
[State the single primary goal of the task]

### C — Context
[Explain WHY this task is needed and how it fits into the larger LabFlow system]

### T — Task Specification
[Provide explicit, step-by-step instructions on what needs to be built or modified]

### C — Constraints
[List what is FORBIDDEN. e.g., "Do not alter RLS policies", "Do not touch app/actions/"]

### F — Format
[Specify the expected output format, e.g., "TSX Component", "SQL Migration file"]
```
